# Primordial Weave · Sources

This directory contains actual brand and background assets; it is **not** empty or reserved.

- [backgrounds/](backgrounds/) — three **clean AI scenic background plates** with no logos, text or seals: `金线云岭水墨长卷.png` (2172×724), `金色织境云谷山水.png` (1731×909), and `金线流韵山河图.png` (1774×887).
- [logo/](logo/README.md) — approved mark/seal input art, wordmark source references, manifests, and Python scripts for precise compositing.
- [seal/](seal/README.md) — approved seal version histories and quality records.

**Scenic build:** `python3 sources/logo/scripts/compose.py` reads the above backgrounds plus the approved PNGs in `exports/png/` and generates results under `build/scenic-v1.2/`, without overwriting any published files.

[Scenic Manifest](logo/scenic-exports-manifest-v1.2.json) · [QA](logo/SCENIC-ASSETS-QA-V1.2.md) · [CHANGELOG](../CHANGELOG.md).
