# Brand exports

Approved and historical assets are now stored under the following paths:

- [PNG](png/README.md) — Marks, seals, wordmarks, avatar and README banner.
- [OG](og/README.md) — Open Graph share and GitHub Social Preview, which still use an older seal.
- [Favicon](favicon/README.md) — 16/32/48/256px PNG plus ICO.
- [SVG](svg/README.md) — the accepted trace of the 「織」 glyph; not a vector reconstruction of the complete Mark.

**Current identities:** seal V1.4 and standard Mark V1.2 centered, approved 2026-11-09. See [release manifests](../sources/seal/manifest.json) and [Mark manifest](../sources/logo/manifest.json). Legacy V1.1 files are archived in place; the public repository does not confer a general brand license.
