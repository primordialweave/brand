# Logo 使用规范 · 当前工作基线

> 状态：待正式视觉批准。**本仓库暂未上传 Logo 图片、SVG、PNG 或母版。**

## 1. 核心组合

- 中央：传统黑白太极的结构意象，保留清晰阴阳分界和两枚鱼眼。
- 外部：一条具有笔触方向感的单一水墨圆环，避免繁复金属环和星轨。
- 细节：极细暖金内圈、上下克制朱砂点（仅在足够尺寸下保留）。
- 印章：不是核心图形不可拆分的一部分；标准展示版可以在右下外置，详见 [印章规范](seal-usage.md)。

## 2. 预期版本

| 版本 | 适用 |
| --- | --- |
| 极简 Mark | 组织头像、小图标、日常软件界面 |
| 标准带印 Mark | 正式介绍、宣传封面、部分 README 图片 |
| 横向字标组合 | 网站页眉、品牌文档、对外宣传 |
| 深色 / 浅色 / 单色 | 多背景与印刷用途 |
| 响应式 Favicon | 16–32px，仅保留最强几何辨识特征 |

上述版本仅是规范需求，**不是已上传文件清单**。

## 3. 安全距离与尺寸

- 周边留白建议不小于外圈直径的 **10%**；具体以正式光学修正后的母版为准。
- 标志与并排标题之间建议保留不少于标志直径的 **0.18 倍**空间。
- 标准印章建议独立显示宽度 ≥64px；较小场景直接使用无印章版。
- 在 16/32/64px、浅/深背景和圆形裁切中逐一验收，确保鱼眼和墨环不糊在一起。

## 4. 不允许的改动

- 任意拉伸、镜像、倾斜太极或改变黑白旋转关系。
- 从预览拼板里裁切放大，或单独重新生成近似但几何不同的 Mark。
- 以大量高饱和金红、光晕、浮雕、珠宝描边替代水墨克制美学。
- 随意改变印章四边宽度、篆字结构或印章与 Mark 的相对位置。
- 把 PNG 内嵌到 SVG 后称为「完全可编辑的路径矢量母版」。
