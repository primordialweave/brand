## 2. 印文与视觉性质

- 以繁体字「織」为意象，呼应 *Weave*，使用朱砂红、仿手工印泥颗粒、边缘残缺与透明的印文空白。
- 统一保留正方形整体比例、原图墨迹、透明 Alpha，不拉伸、不镜像、不随意变色。
- 这是**品牌艺术化篆刻文字**，不代表严格依据某个历史印谱摹刻。不得宣称《说文》原样、古代真印还原或已获标准小篆认证。
- 小尺寸头像、favicon 推荐省略复杂印章，避免印文糊成一团。

## 3. 品牌组合和更新边界

- 可用于 README 文档、品牌落款、介绍海报以及未来网站，但印章是主品牌的辅助识别，不替代完整组织名称。
- 未来 Mark、Banner、OG 等若新增或调整印章，**一律使用此版本的同一透明 PNG**，保证字形与印迹一致。
- **本次仅维护文档与版本登记：不替换现有 Mark、Banner、OG、头像或其他图片。**
- 宣纸版本仅是展示样张，不可当作透明图叠加到其他场景。
