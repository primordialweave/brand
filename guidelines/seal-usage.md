# 朱砂「織」字印章 · 使用与考证规范

> 状态：**图形概念确定；小篆字形尚未取得逐笔专业校核，不应宣称为历史准确的标准小篆印。**
>
> 此轮只维护文字规范，**不上传任何印章图片或 SVG**。

## 1. 印文与意义

- 印文：`織`，为简体「织」的繁体字。
- 与品牌中 `Weave`（交织）直接呼应。
- 用于落款、文化辨识与作品的辅助识别，不应替代 Primordial Weave 的完整名称。

「織」字结构按左「糸」右「戠」理解，但这只能说明现代构字分析，不等于已经核实所有小篆具体笔画。须使用权威字书或可靠篆体资料及专业审校。

## 2. 版式结构

- 建议单字方章，方框四边视觉厚度统一，印文在有效印面内居中。
- 优先采用朱砂红；印边略有石刻质感，但不能因此使右边明显比左边更宽。
- 工作稿的参考值：1024px 画布内约 750×750px 印框、四边名义厚度 34px、角半径 16px；这只是 **S1 PNG 工作稿的几何基线**，不是不可修改的古法印制规范。
- 轻微自然纹理可保留，严禁倾斜压缩、镜像和重新生成形似而笔画不同的印章。

## 3. 与主 Logo 的关系

- 标准 Mark：放在右下角外侧，与墨环保持可见间隙。
- 横向 Banner：可位于标题旁或图形右下，不能遮挡英文名称或标语。
- 极小头像和 favicon：默认省略印章。
- 所有使用印章的材料必须来自**唯一核准母版**，禁止多张图各自生成一枚印章。

## 4. 正式校验程序

1. 核实「織」在规范古文字资料中的实际篆形及出处。
2. 对照目标印面逐笔核查部件形态、横竖曲折与留白。
3. 由熟悉篆书/篆刻的人员二次复核，并记录审校人、日期、证据。
4. 统一正方形边界、配色、印文比例，完成实用尺寸测试。
5. 批准后才导出正式路径、透明底 PNG 与在不同物料上的使用版本。
