# Brand Assets · Rights & Licensing Policy (Draft)

> **IMPORTANT:** Publicly viewable is not the same as open-licensed. This document is a proposed usage policy; it is **not** a license grant and has not received final rights-holder approval.

## Categories

| Resource | Current treatment |
| --- | --- |
| Organization name / logo / Taiji-derived mark | Brand identity; seek explicit permission before adaptation or commercial use |
| `織` seal, illustrations, banners and OG images | Brand creative; approval, provenance and glyph validation pending |
| Font names and typography token references | Design data only; do not redistribute actual font files |
| GitHub organization docs | Public documentation; separate license decision needed for broad republication |
| Software source in other repositories | Governed by the **specific project's** LICENSE if and when one is published |
| Third-party artwork / code / data | Subject to its own rights and verified source license |

## Before publishing actual brand graphics

- [ ] Identify creator/source and original files.
- [ ] Verify third-party reference and font licenses.
- [ ] Review historically specific claims and `織` glyph accuracy.
- [ ] Approve the exact binary or vector master.
- [ ] Record filename, version, SHA-256, reviewer, and release date.
- [ ] Decide whether and how others may reuse, remix, redistribute or commercially use each asset.
- [ ] State those permissions explicitly in a dedicated LICENSE or usage agreement.

## Explicit restrictions at present

There is **no approved general-use brand asset license** in this repository. Do not assume a project's MIT, Apache or other code license covers the Primordial Weave emblem, seal, typography, banners or creative illustrations.

This draft does not override copyright law, trademarks, or other existing legal rights. Consult the rights holder for authorization where needed.
