## 一、目的与绝对约束

这是对已经定稿的**极简 Mark V1.0**与**「織」字朱砂印章 V1.1**的固定坐标组合，**不是重新设计 Logo**。

- 只允许**等比例缩放、透明裁边、RGBA Alpha 合成**；不得用图像模型重新生成、重画、擦除或补绘太极、金线、墨环、朱砂点、印文字形。
- 必须保留白色鱼身、黑色鱼眼、白色鱼眼及印章白文镂空；原图中已有细腻墨纹应保留。
- 不得新增任何红黄杂边、金色光晕、背景纹理、投影、金属描边或其他装饰图层。
- 背景保持真实透明；浅色和深色预览 JPG **不是**透明交付文件。
- 禁止用上轮重新生成且污染严重的标准 Mark 作为新母版。

## 三、2048px 精确排版参数

坐标从画布左上角 `(0,0)` 起算，PNG 像素坐标，单位 px。

| 图层 | 最终尺寸 | 位置（左上角） | 操作 |
| --- | --- | --- | --- |
| RGBA 透明画板 | 2048×2048 | `(0, 0)` | sRGB、无背景填充 |
| 极简 Mark | **1760×1760** | **`(55, 50)`** | 完整源图等比例缩放，不裁除内部阴阳元素 |
| 白文「織」朱砂印章 | **304×304** | **`(1480, 1460)`** | 裁 Alpha 外缘（阈值 12，保留 12 原始像素缓冲），等比例缩放 |
| PNG 导出 | 2048×2048 | `(0,0)` | 保留 Alpha、RGBA |

### 与上一版的唯一变化

| 参数 | V1.0 | **V1.1（本版）** |
| --- | ---: | ---: |
| 主 Mark 坐标 | `(55,50)` | **`(55,50)`** |
| 主 Mark 尺寸 | 1760 | **1760** |
| 印章尺寸 | 304 | **304** |
| 印章坐标 | `(1585,1577)` | **`(1480,1460)`** |
| 印章位置变化 | — | **向左 105px，向上 117px** |
| 原始素材 / 色彩 | 锁定 | **完全不变** |

印章与墨环之间的有效像素应保持短而明确的视觉间隙：本次合成在 Alpha>20 的可见区域**没有交叠**，最近间距约 **52px**（高分辨率测量，数值为像素近似值）。以此作为新版建议定位，而非让印章碰触墨环。印章距画板右缘约 264px、下缘约 284px，留白仍充足。

**注意：** 印章的**白文**即红印面内部镂空的印文，放在深色背景上呈现为背景色，而不是额外涂白的字体。不要对印章的字形做反相或改色操作。

## 四、软件内按图层执行

1. 创建 2048×2048 px 透明 RGBA / sRGB 画板。
2. 导入锁定主体 PNG，缩放至 1760×1760，设 X=55，Y=50。关闭图层特效并锁定。
3. 导入锁定印章 PNG，按 Alpha>12 的内容包围框裁去外围透明画布，再于裁框周围保留 12 原始像素的缓冲边。
4. 将裁后印章缩放至 304×304，设 X=1480，Y=1460。**不要将其贴到太极上**，而是靠近外部水墨圆环的右下方。
5. 检查印章与墨环有足够空间、印面边框四边完整、太极鱼眼正常；背景四角 Alpha 必须为 0。
6. 临时叠加宣纸背景 `#F8F4EC` 与深炭色 `#1C1D1F` 检查明暗效果，**预览背景不可烘焙进正式 PNG**。
7. 导出 `pw-mark-standard-seal-v1.1-2048.png`（2048×2048、RGBA、透明）。

Figma/Affinity/Photoshop 的图片裁边设置可能不同，无法确定像素裁框时，优先使用随包 Pillow 脚本，其结果更可复现。

## 五、可执行脚本

```bash
python3 -m pip install Pillow
python3 sources/logo/scripts/compose_mark.py
```

脚本自动校验两张母图 SHA-256，按本规范固定参数执行透明裁边、LANCZOS 缩放和 `alpha_composite`，并在 Alpha>20 阈值下检测两图层是否碰撞。**必须保留哈希校验，不要跳过。**

产生的文件：

```text
build/standard-mark-v1.1/
├── pw-mark-standard-seal-v1.1-2048.png   # 真透明交付候选
├── proof-light-800.jpg                  # 浅色查看用
├── proof-dark-800.jpg                   # 深色查看用
└── QA.json                              # 输入/输出哈希、排版参数和碰撞检测
```
