# Primordial Weave · 标准 Mark V1.2 初始定位草案（历史记录）

> **历史草案，不作为当前正式合成规范。**  
> 此文件保留 V1.2 的早期「Mark Square 右下角内侧齐边」讨论与变更背景。当前经品牌方确认的**实际正式坐标、文件与验收记录**均以 [V1.2 居中正式规范](MARK-COMPOSITION-SPEC-V1.2-CENTERED.md) 为准。

## 1. 草案背景

早期标准 Mark V1.1 使用极简 Mark 1760×1760 于 `(55,50)`，印章 304×304 于 `(1480,1460)`。V1.2 最初尝试让印章以墨环 Mark Square 的右下边缘为定位基准，以消除自由落款的漂浮感。

首次按旧主图坐标检测到 Mark Square `(174,160,1698,1684)`，严格齐边计算得出印章坐标 `(1394,1380)`。**这个候选的 Mark Square 中心是 (936,922)，未落在 2048×2048 画布中心 (1024,1024)，因此没有被定稿。**

## 2. 后续居中修订与已批准结果

为了同时实现整体居中和右下角结构关系，在保持图形尺寸不变的前提下，将主图及印章整体向右 88px、向下 102px：

| 图层 | 初始候选 | **正式 V1.2 居中版** |
| --- | --- | --- |
| 主 Mark（1760×1760） | (55,50) | **(143,152)** |
| Mark Square | (174,160,1698,1684) | **(262,262,1786,1786)** |
| 印章容器（304×304） | (1394,1380) | **(1482,1482)** |
| 印章来源 | V1.1（旧参考） | **V1.4 确认字形** |

正式版印章容器的右/下边缘仍各为 `1786`，与调整后 Mark Square 的右/下边界一致；**关键区别在于整体居中、正式印章更新及锁定坐标**，而不是与旧图形成相同绝对位置。
