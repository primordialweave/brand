# Primordial Weave · 品牌定位与视觉原则

> **状态（2026-11-07）：** 极简 Mark V1.0、标准带章 Mark V1.1 及「織」字印章 V1.1 的 PNG 已在 brand 仓库正式登记并上传。标准 Mark 已获品牌方视觉确认；其他 Banner、OG、头像、深色版和 SVG 尚未统一，文档也不构成公共授权。

## 1. 品牌基础

| 项目 | 当前表达 |
| --- | --- |
| 英文名 | **Primordial Weave** |
| 中文名 | **原初织界** |
| 英文标语 | **Inspired by ancient wisdom. Built for the open future.** |
| 中文标语 | **灵感源自古老智慧，创造面向开放未来的工具。** |
| 组织定位 | 中国传统哲学与水墨美学启发的开放技术、工具与数字文化项目 |

`Primordial` 表达「太初、本源」，`Weave` 表达「交织、连接、构成」。整体语义是以开放协作将不同知识、工具和创造连为系统。英文名是现代意译组合，不应伪称为古籍原文。

## 2. 品牌的文化表达

- 主要思想：道的生成观、阴阳互补、万物相联、自然变化。
- 主要视觉：黑白太极、一笔水墨圆环、宣纸留白和极少量朱砂印意。
- 次要语言：淡墨远山、纸纹、传统题签感；用于横幅和场景，而非全部堆叠在一个小图标里。
- 现代化约束：简单、清晰、可维护、易辨识；文化应增强使用体验，而不是取代功能。

这些是设计借鉴，不等同于任何朝代器物、某一历史星图或宗教符号的精确复刻。需要具体历史依据时，请附可核对的来源。

## 3. 视觉层次

1. **墨黑与纸白**：最重要的识别层次。
2. **灰阶水墨**：传达山水、层次与墨韵。
3. **朱砂红**：仅用于印章、标识点睛。
4. **淡古金**：极细辅助线，不使用金属浮雕或大面积高光。

候选值以 [colors.json](../design-tokens/colors.json) 为准。它们来自最近一次 S1 PNG 工作稿，待正式视觉审阅后才能升级为 approved。

## 4. 版式与文案

- 品牌英文始终书写为 **Primordial Weave**（两个词，首字母大写）。
- 中文品牌名用 **原初织界**，作为现代命名，不加「古籍记载」之类未经证实的表述。
- 英文标题建议 EB Garamond；中文标题建议 Noto Serif CJK SC。
- 软件界面与说明文字优先清晰可读的无衬线字体，不滥用书法字体。
- 国际传播优先准确介绍工具、功能和状态；哲学叙述作为辅助层。

## 5. 使用场景与尺度

- 小尺寸：尽量使用无印章简化 Mark；favicon 可以采用响应式几何简化版本。
- 横幅：左图右字或以留白为主，确保英文名和标语在窄屏仍可读。
- 系统图标：避免复杂纹样、过多金线以及过度阴影。
- 图像生成产物：必须核对文字、印章和统一图形，不应直接把模型输出当作严谨矢量母版。

## 6. 旗下项目

Dao（道）、Taiji（太极）、Fangcun（方寸）、Shanhai（山海）等名称可作为文化命名方向，但名称应服从真实产品功能。子项目可以拥有独立图形、附加色和字体层级，不能擅自扭曲母品牌 Mark 或印章。
